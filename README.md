# TubeFlow AI Web 原型

这是一个不依赖前端框架的桌面端交互原型，覆盖：

- 多频道创建、编辑、切换与删除（仅无项目的空频道）
- 每个频道下的多视频项目管理
- 文案、演示时长回填、故事板、视频、预览、合成与导出步骤
- 图中标记“暂时不做”的能力以禁用入口保留
- 浏览器本地存储与真实 `.srt` 下载

## 启动

```powershell
npm run dev
```

浏览器打开 `http://127.0.0.1:4173`。

也可以直接双击 `index.html` 查看页面；使用本地服务时素材加载更稳定。

## 检查

```powershell
npm run check
```

当前版本不连接后端，不会调用真实配音、图片或视频生成服务。手动回填的时长只用于前端原型布局，不会开放 MP4 或可执行视频任务导出。
