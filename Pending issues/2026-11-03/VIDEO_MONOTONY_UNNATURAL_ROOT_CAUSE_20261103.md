# 成片画面单调、不自然：根因汇总与本次修改

日期：2026-11-03
范围：代码只读排查 + 提示词层修改（含自动化测试）；未调用任何真实 Provider，未部署，未修改生产数据。

## 1. 问题现象

用户反馈：视频画面单调、不自然，难以吸引观众观看。

## 2. 根因（按影响排序）

| # | 现象 | 根因 | 位置 |
| --- | --- | --- | --- |
| 1 | 同一画面持续 10–15 秒 | 前置导演 v8 单元提示词要求“除非存在多个独立叙事事件，否则只返回一个镜头”，且“只改景别或机位不构成新镜头”；单元为 3–6 句。v8 之前组均约 2.4 镜（1 镜×15 / 2 镜×47 / 3 镜×55 / 4 镜×14）。 | `application/project_director.py` 单元提示词 |
| 2 | 人物在每格保持同一坐姿/托腮 | 频道与项目画面风格含“保留原图姿势、表情、主体数量、场景布局和物品位置，仅转换画面艺术风格”，原样进入每组故事板生图提示词。 | `Pending issues/2026-11-03/STORYBOARD_REFERENCE_POSE_ROOT_CAUSE_20261103.md` |
| 3 | 视频换人、多出人物 | 视频提示词编译器与前置导演都看不到图片，却被要求写人物外观（v3 第 5 条），臆造的发型/服装/人数与正确参考图冲突。 | `Pending issues/2026-11-03/video-ip-inconsistency-evidence-20261103.md`；`video_prompt/templates.py` v3 第 5 条 |
| 4 | 抖动、漂移、不自然运动 | v3 第 8 条强制每镜量化运镜，示例教授环绕、荷兰角、旋转；78 组实测静止组 HF≈0.03–0.06，运镜组均值≈0.57。 | `video_prompt/templates.py`；`docs/VIDEO_JITTER_DIAGNOSIS_20261018.md` |
| 5 | 文字/数字闪烁、格线与角标泄漏 | 镜头要求模型画数字与标签；故事板烧入 `SHOT n · 时间` 角标。 | `application/storyboard_prompt.py`；`docs/HANDOFF_MULTI_PANEL_LEAK_20261020.md` |
| 6 | 留存差 | 合成仅顺序拼接：无配乐、无字幕、无开场钩子处理。 | `adapters/ffmpeg.py` `compose()` |

补充：角色参考图为三视图（正/侧/背），未说明“多视角仍为一人”时可能诱发重复人物；H3 请求 `seed` 为空，无法复现与公平对照。

## 3. 本次修改（分支 `claude/video-quality-v4-v9`）

1. 前置导演单元提示词 v9，仅新项目使用（USER_DECISIONS §41）：约每句一镜、B-roll 式覆盖、单元内不重复 scene+景别+机位组合、允许场景内自然道具、禁止描写角色外观、参考图外人物只作背景。项目在首轮导演运行时钉住版本；既有项目 v8 提示词、单元请求哈希与运行 canonical 输入与改动前黄金值逐字一致，AUTO 恢复不整轮重跑。
2. 视频提示词模板 `tubeflow_storyboard_v4_natural_motion`（可选，默认仍为 v3）：运镜白名单与幅度上限、主体动作驱动、真实速度、禁止画内文字；角色主体只写 `the person in character reference N`，禁止任何外观描写与超出参考图数量的主体；负规则加入 extra people、duplicated characters。输出合同与 v3 相同。
3. 故事板提示词（USER_DECISIONS §42，用户已接受第 1 项）：参考图只作身份参考，不得复制姿势/手势/表情/构图/机位/布局/物品位置，分镜优先，多视角仍为一人。

## 4. 仍需用户执行或决定

- 从频道默认画面风格中删除“保留原图姿势……仅转换画面艺术风格”一句（数据修改，冻结项目不改写）。
- 选 3 组用固定 seed 对比 v3 与 v4（人物一致性、HF 抖动），通过后再决定是否设 v4 为默认。
- 首个 v9 新项目观察每组镜头数分布、`director_output_adjacent_diversity_insufficient` 重试率与组级非相邻构图重复暂停。
- 是否：停止故事板烧入角标、默认单格参考、合成配乐/字幕/开场钩子、确定性 seed（均触及既有决策，待定）。
