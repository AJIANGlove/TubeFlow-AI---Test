## 5. 测量与判定（写定，事后不改）

测量：`../round2/measure_motion.py` + 本目录 `spec.json`（固定时间段 + 相关性保护，见 `../round2/ANALYSIS.md` 第 2 节；时间段被收缩时如实标记）。
