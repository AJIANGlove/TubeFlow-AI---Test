# 画面运动自然度：配角与环境静止（2026-11-09 立项）

**问题（用户 2026-11-09 目视）**：项目 `2280f7c6`（Maya）成片 23:51.8–24:01.8 的船上镜头，背景和两名配角「太僵硬、不自然」；在小船上做这种动作，船应自然摇晃，水面应随之起波纹。

**目标**：主角以外的人物有自然的小动作，环境（水、船、雾、树、火光）有与场景相符的自然运动；不能因此带回抖动、变形、闪烁或多余人物（v4 的既有成果）。

用户 2026-11-10 补充（看第 2 轮后）：湖岸应「随着起风了，然后一起摆动，雾气也是一个方向」；船上不能出现岩芯突然拉长之类的变形。

**工作方式（用户 2026-11-09 指示）**：Claude 分析原因、设计测试 → 实施方 AI 执行并反馈 → Claude 据反馈定位根因、给出下一轮优化，循环直到用户目视认可。

## 4. 已验证的写法（供编译规则使用，2026-11-12）

1. **按分格图写出画面里的每个人和物，并各给一个自然动作**（第 2 轮：船上配角、船、水的运动约为原来的 3–5 倍）。
2. **主角动作与分格图的起始状态一致**，物体尺寸与形状保持不变（第 3 轮：岩芯拉长消失）。
3. **环境运动统一成一股风、一个方向**（第 3 轮：云、雾、水纹同向后通过风向检查），**方向用场景参照物写，不用画面左右**（第 3 轮衣摆与云相反；第 4 轮验证中）。
