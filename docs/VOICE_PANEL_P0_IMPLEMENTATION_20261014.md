## 4. 行为变化摘要（验收要点）

1. 源卡切换只改变"正在查看的源"，不影响频道配置；「当前使用」角标全局唯一。
2. 在任一源内对某音色点「设为频道默认」：立即生效；跨源时频道配音源自动切换（提示明示），不存在"先设置音色、再切源被拦回"的情况。
3. 克隆提交：仅表单冻结 + 「请保持页面打开」提示；成功＝结果卡常驻 + 新条目高亮、**不自动变更默认**；失败＝结果卡常驻 + 表单保留 + 「重试」按钮。
4. 删除任意可删音色需二次确认；默认音色与"被冻结项目/草稿引用"的音色禁止删除且原因可见。
5. 文案：第二级入口为「使用已有音色」；按钮为「设为频道默认」/「使用中」；空状态不再出现"号池"等内部术语。
