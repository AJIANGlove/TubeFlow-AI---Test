## 3. 先看这些结论

1. **【已确认】创建项目不等于开始生产。** `POST /identity/projects` 只创建草稿；当前创建路径把 `production_mode` 固定为 `AUTO`，此时尚未创建配音、导演或 AUTO 运行。
2. **【未找到相关实现】自动撰写完整脚本的生成链。** 项目创建输入直接接收用户粘贴的 `script`；AUTO 提交前另有“超长句拆句 agent”，它不是完整脚本生成器。
3. **【已确认】当前前端的生产入口是 `POST /narration/confirm`。** 该入口先按风险执行拆句，再在事务中冻结快照、创建配音任务、创建 AUTO 运行和前置导演意图。
4. **【已确认】配音与前置导演可并行。** 两者由同一提交事务分别写入 outbox，并由不同 relay/workflow 推进；代码不保证谁先完成。
5. **【已确认】AUTO 主链到“当前成片存在”即完成。** 不自动生成封面，也不自动导出 ZIP；封面与导出均是独立用户动作。
6. **【未找到相关实现】对外完成通知。** 当前仓库未见对外业务 webhook、SSE、WebSocket 或邮件通知；内部推进使用 `auto_kick` 和周期巡检，前端使用 HTTP 轮询。
